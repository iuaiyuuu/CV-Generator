## Notes for the AI

- Use this file for the **reason and direction** in the Summary (`rules/03-writing-style.md`), for cover-letter angles, and for interview preparation.
- Never copy trait adjectives into the CV. Show the trait through its story and proof file.
- Never add a fact that is not written here or in another file of `profile/` or `info/`.
- If a story has no proof file yet, treat it as unverified and ask the user before using it.
