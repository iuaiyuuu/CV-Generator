# profile/

Your identity and background. **Private — git-ignored.** Only this README and `*.template.md` are tracked.

## Setup

Copy each template and remove `.template` from the name:

| Copy | To | Contains |
|---|---|---|
| `personal.template.md` | `personal.md` | Name, contact, links, target roles, languages |
| `education.template.md` | `education.md` | Schools, degrees, GPA, coursework, honors |
| `experience.template.md` | `experience.md` | Jobs, internships, volunteering, organizations |
| `story.template.md` | `story.md` | Your story and personality: what pulls you, how you work (each trait with one real example), what you want next, what you will not claim |

Fill in only facts you can stand behind. The AI uses these files as the **only** source of truth about you (see `rules/01-truthfulness.md`).

Tip: write raw, honest detail here (tasks, tools, numbers). The AI will select and rephrase per job; you don't need to polish.
